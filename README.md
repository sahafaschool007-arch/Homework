# منصة الواجبات - مدارس الصحافة الأهلية

نسخة منشورة من منصة متابعة الواجبات الأسبوعية (القسم الابتدائي والقسم المتوسط).

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | المنصة كاملة (صفحة واحدة) |
| `data.enc.json` | البيانات مشفّرة بكلمة مرور الدخول (AES-256-GCM) — تُنزَّل من المنصة الأصلية |
| `.nojekyll` | يمنع GitHub من معالجة الملفات |

## النشر لأول مرة

1. أنشئ مستودعاً جديداً على GitHub (مثلاً `homework-platform`).
2. ارفع `index.html` و `.nojekyll` و `data.enc.json` إلى جذر المستودع.
3. من **Settings → Pages**: اختر **Deploy from a branch**، والفرع `main`، والمجلد `/ (root)`، ثم **Save**.
4. بعد دقيقة يظهر الرابط: `https://اسم-المستخدم.github.io/homework-platform/`

## تحديث البيانات كل أسبوع

1. افتح المنصة الأصلية ← **الإعدادات** ← **ملف النشر على GitHub**.
2. اكتب كلمة مرور الدخول واضغط **تنزيل data.enc.json**.
3. في المستودع: **Add file → Upload files** وارفع الملف الجديد ليستبدل القديم ← **Commit**.

## ملاحظات

- الدخول في النسخة المنشورة يتم بفك تشفير البيانات؛ كلمة المرور غير مكتوبة في الكود.
- التعديلات داخل النسخة المنشورة لا تُحفظ؛ التعديل يكون في المنصة الأصلية ثم يُعاد تنزيل الملف.
- تنزيل PDF و Excel يعمل من النسخة المنشورة.
